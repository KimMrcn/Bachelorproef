# Bachelorproef

## Repository kopiëren naar je eigen GitHub-account

Als je deze repository naar je eigen repositories wil kopiëren:

1. Open deze repository op GitHub.
2. Klik rechtsboven op **Fork**.
3. Kies je eigen account als bestemming.
4. Open daarna je geforkte repository via `https://github.com/<jouw-gebruikersnaam>/Bachelorproef`.

### Lokaal klonen van je eigen kopie

```bash
git clone https://github.com/<jouw-gebruikersnaam>/Bachelorproef.git
cd Bachelorproef
```
